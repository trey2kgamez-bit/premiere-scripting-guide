# Premiere Pro Scripting Guide

This repo hosts the Premiere Pro Scripting Guide community docs.

---

## Run the docs locally

> Note: this repository is a documentation site, not a standalone video editing application runtime.

1. Install Python 3.10+.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the local docs server:

   ```bash
   mkdocs serve
   ```

4. Open http://127.0.0.1:8000 in your browser.

### Build static site

```bash
mkdocs build
```

The generated site output is written to `site/`.
